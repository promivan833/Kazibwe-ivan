KAZIBWE IVAN — Official Personal Portfolio

Live site:
https://promivan833.github.io/Kazibwe-ivan/

Repository:
https://github.com/promivan833/Kazibwe-ivan

Main files:
- index.html: page content, metadata and structured data
- style.css: responsive layout, themes and visual styling
- script.js: mobile navigation, theme preference and active navigation
- favicon.svg: browser icon
- images/: images used by the site
- sitemap.xml and robots.txt: search-engine discovery files

Maintenance:
1. Edit the relevant source file in the repository.
2. Check local links, image paths, responsive breakpoints and both color themes.
3. Commit changes to the main branch.
4. Wait for GitHub Pages deployment, then verify the live URL on mobile and desktop.

The current site does not use a photo gallery or lightbox. Add those features only if matching HTML markup and real image assets are supplied.
